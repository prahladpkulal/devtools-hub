What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit identifier commonly used for database records, API resources, distributed systems and application objects.

What is UUID v4?

UUID version 4 generates an identifier using random or pseudo-random data with the version and variant bits set according to the UUID format.

How to generate a UUID

Choose how many identifiers you need, select a case, and click Generate UUIDs. You can generate up to 100 identifiers at once and copy the output.

FAQ

Are generated UUIDs stored?

No. The identifiers are generated in your browser and are not sent to a server by this tool.

Can I generate multiple UUIDs?

Yes. Enter a value from 1 to 100 and generate them in one operation.
