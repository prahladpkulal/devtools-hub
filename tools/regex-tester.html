Regex Tester

Test a JavaScript regular expression against sample text and inspect matches and capture groups locally.

What is a regular expression?

A regular expression, or regex, is a pattern used to find, match or replace text. Regex is widely used in programming, validation, log analysis, search and data cleanup.

How to use the regex tester

Enter a JavaScript-compatible pattern, choose flags such as g, i or m, paste your sample text and select Test Regex. The result lists matched text, positions and capture groups.

Common regex flags

g finds multiple matches, i ignores case, m changes how line anchors work, and s lets the dot match line terminators.

FAQ

Which regex engine does this use?

This tester uses the regular expression implementation built into your browser's JavaScript engine.

Is my test text uploaded?

No. The regex test runs locally in your browser.
