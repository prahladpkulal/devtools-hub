What is a JWT?

A JSON Web Token (JWT) is a compact token commonly used to carry claims between applications. A JWT normally has three Base64URL-encoded parts: header, payload and signature.

How to decode a JWT

Paste the token above and select Decode JWT. This tool parses the header and payload locally in your browser and displays the JSON in readable form.

JWT decoding vs verification

Anyone who has a JWT can decode its header and payload. Decoding only reads the token; it does not prove that the token was issued by a trusted service or that its claims are valid.

FAQ

Is my JWT uploaded?

No. This page performs decoding in your browser.

Can this tool verify a JWT signature?

No. It is an inspector, not an authentication or signature-verification service.
