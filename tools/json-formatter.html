Format, validate, pretty-print or minify JSON directly in your browser.

About the JSON formatter

Use this free JSON formatter for API responses, configuration files, logs and debugging. Processing happens in your browser, so your JSON does not need to be uploaded to a server.

How to format JSON

Paste valid JSON into the editor and select Format. The tool validates the JSON and adds readable indentation. Select Minify when you need compact JSON.
