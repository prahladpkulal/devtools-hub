INSTALL FOR DEVELOPMENT

Load the extension in Chrome

  1. Clone or download the DevTools Hub repository.
  2. Open chrome://extensions in Chrome.
  3. Enable Developer mode.
  4. Choose Load unpacked.
  5. Select the extensions/chrome folder.

This project is prepared for local testing first. A Chrome Web Store listing can be added after the production build, store assets and privacy review are complete.

WORK YOUR WAY

Three ways to use it

1. Popup

Click the toolbar icon, search for a tool and work in a compact interface.

2. Side panel

Open DevTools Hub beside the current webpage and keep your toolkit visible.

3. Right-click

Select text, right-click and send it to Base64, URL, JSON, JWT or other actions.

PRIVACY

Designed to keep developer data local

Core transformations are implemented with browser JavaScript and do not require an application server. Avoiding unnecessary network access keeps the extension simple, fast and easier to trust.
