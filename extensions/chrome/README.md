# DevTools Hub Chrome Extension

A Manifest V3 browser toolkit that brings common developer utilities into Chrome.

## Included

- JSON formatter and minifier
- Base64 encode/decode
- URL encode/decode
- JWT decoder
- UUID generator
- SHA-256 hash
- Unix timestamp converter
- Regex tester
- Case converter
- HTML formatter
- URL parser
- Hex color converter
- Simple text diff

## Chrome features

- Toolbar popup
- Side panel
- Right-click actions for selected text
- Local browser processing for core tools
- Dark mode by default, light mode available
- Searchable tool list
- Link back to DevTools Hub web tools

## Load locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `extensions/chrome` directory.
5. Pin DevTools Hub to the Chrome toolbar.

## Project pages

- Web extensions landing page: `/extensions/`
- Chrome extension page: `/extensions/chrome/`

The current build is intended for local development/testing. Chrome Web Store publishing should be completed only after final QA, store assets, privacy disclosures and permissions review.
